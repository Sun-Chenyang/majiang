## 1. 设计定位

**现代清新微拟物 + 玻璃拟态（Modern Fresh Skeuo-Glassmorphism）**

- 色调：通透、极简、高明度淡彩；
- 材质：半透明磨砂玻璃（BackdropFilter）+ 微立体触感（双层柔影、按压物理反馈）；
- 禁止：发脏的深灰阴影、高饱和撞色、无意义的扁平线框、双层描边。

## 2. 全局光照规则（最高优先级）

**所有渐变和阴影固定光源方向：左上 → 右下（Top-Left → Bottom-Right）。**

| 规则 | 实现 |
|---|---|
| 受光面（渐变亮端）永远在 `topLeft` | 渐变统一 `begin: GlassLight.begin → end: GlassLight.end` |
| 投影永远朝右下 | `BoxShadow.offset` 的 x/y 均为正值 |
| 凹槽内阴影相反：顶部内侧背光（暗）、底部内侧受光（亮） | 见 GlassInputField 的 `_EdgeInnerShadowPainter` |
| 环境底图顶部有白色高光斑 | `AmbientGlassBackground` 编队表最后一枚 |

任何新组件必须遵守此光照语言，否则立体感互相矛盾。
**暗色主题下方向同样不变**（不变式 3）：暗色的"受光"指相对提亮
（低透明白、更高 alpha 的亮端），而非切换光源方位。

## 3. 色彩令牌（`GlassColors`）

### 品牌色板（高明度淡彩）

| 令牌 | 值 | 语义 |
|---|---|---|
| `mint` | `#64D2B7` | 主色：成功 / 听牌 / 默认强调 |
| `iceBlue` | `#70B6FF` | 辅色：计算 / 进张 / 次强调 |
| `lavender` | `#A58BFF` | 点缀：庆祝 / 设置 |
| `canvas` | `#F8FAFC` | 画布基色（冷灰白） |

### 深化色（浅色玻璃面上的文字/图标，保证对比度 ≥ 4.5:1）

`mintDeep #0D9C80` · `iceDeep #2E6FD0` · `lavenderDeep #6F4FD4`
——浅底上**禁止直接用品牌色做文字**，必须用对应 Deep 色。

### 功能色

| 令牌 | 值 | 语义 |
|---|---|---|
| `warning` / `warningDeep` | `#FFB454` / `#AD6410` | 提示 / 打牌建议 |
| `danger` / `dangerDeep` | `#FF8FA3` / `#D6385F` | 错误 / 张数有误 |
| `neutral` / `neutralDeep` | `#9DB0BC` / `#5F7482` | 中性态（未听等） |

### 文字色（青灰 slate 系，禁止纯黑）

`textPrimary #1B2A33` · `textSecondary #556774` · `textTertiary #93A3AE` · `textOnAccent #FFFFFF`

### 颜色混合

用 `GlassColorX.lighten(t) / darken(t)`（0~1）。**注意：本工程 Flutter 3.44 的
`Color.r/g/b/a` 均为 0~1 归一化分量**，曾按 0~255 误用导致全局发黑
（已修复并有回归测试 `color_range_test.dart` 锁定，改动扩展前先看该测试）。

### 3.1 暗色令牌与明暗切换（M10，`glass_palette.dart`）

**机制**：`GlassColors` 是 `GlassPalette` 的静态门面。App 根部解析
ThemeMode（白天 / 黑暗 / 跟随系统，默认跟随系统，持久化仅此一项）后把
`GlassColors.current` 指到对应调色板并整树重建。单 Shell 应用全局同一
时刻只有一套主题，业务侧继续写 `GlassColors.mint` 等静态引用即可，
**禁止在 const 上下文引用色彩/字体令牌**（getter 非常量）。

| 语义 | 浅色 | 暗色 | 说明 |
|---|---|---|---|
| 品牌三色 mint/iceBlue/lavender | `#64D2B7`/`#70B6FF`/`#A58BFF` | 同左 | 环境光色相，两套共用 |
| Deep 文字色 | 加深（`mintDeep #0D9C80` 等） | **提亮**（`mintDeep #5CE0C3` 等） | 暗色玻璃面上对比度 ≥ 4.5:1（`dark_palette_test` 锁定） |
| 文字 textPrimary/2/3 | 青灰 slate `#1B2A33/#556774/#93A3AE` | 浅雾 slate `#E9EFF5/#ABB9C6/#74879A` | |
| 玻璃本体 `glassWhite` | 纯白 | 深板岩 `#223041` | GlassCard 缺省 tint |
| 底图基底 ambientBase | `#FDFFFF→#E7EEF7` 三档 | `#1D2735→#0D141E` 三档 | 光斑浓度 ×0.55，色相不变 |
| 投影墨 shadowInk | `#33526B` | 纯黑 | |
| 弹层填充 sheetHi/Lo | 白玻璃 0.66/0.38 | 近实体深板岩玻璃 | 内容可读性优先 |
| 底栏船体 hullHi/Lo | 白 0.14/0.05（近无色） | 深板岩 0.50/0.30 | 通透 vs 体量 |

**白玻璃表面统一走令牌方法**，暗色自动收敛，不许多写裸 `Colors.white`：

- `GlassColors.surface(alpha)`：表面填充（浅色=原 alpha 白；暗色=alpha×0.22 低透明白）；
- `GlassColors.rim(alpha)`：边缘高光/描边（暗色 ×0.35）；
- `GlassColors.tintForGlass(color)`：GlassCard 彩色 tint 修正（暗色向深板岩混 55%）；
- `GlassColors.accentOnGlass(brand)`：品牌色在**暗玻璃面上做文字/图标**时的
  可读变体（浅色原样；暗色换提亮 Deep——基础品牌色亮度不足，底栏选中
  tab 渐变文字走这里）。

**裸露在环境底图上的文字**（页面副标题、搜索提示、列表描述等背景明暗
随光斑流动而定的文字）一律用 `textSecondary` 级（`captionStrong`），
`textTertiary` 仅用于玻璃面上背景可控的装饰性辅助字——tertiary 在
浅色光斑上对比仅 ~2.2-2.6:1，会被穿透淹没。

**不参与反转的元素**：麻将牌面（象牙白实物，靠阴影/描边在暗色底上
自然成立）；彩色渐变徽标/角标（textOnAccent 白字）。

## 5. 形状与光影令牌

### 圆角（`GlassRadius`）

`xs 10`（chip/角标）· `sm 14`（输入框/列表行）· `md 18`（次级卡）·
`lg 24`（主卡片）· `xl 30`（弹层/底栏）· `pill 999`（胶囊）
—— 牌面例外：宽度的 12%。

### 阴影（`GlassShadow`）

双层柔影 = **近影（染色）+ 远影（中性漫反射）**，替代黑灰死影：

- `soft(ambient)`：近影 `ambient α0.20 / blur14 / offset(2,6)` +
  远影 `shadowInk α0.10 / blur30 / offset(8,18)`；
- `chip(tint)`：小元素单影 `α0.18 / blur8 / offset(1,3)`；
- `pressed(accent)`：按压贴地影 `α0.22 / blur4 / offset(0,1)`。

### 动效时长（`GlassDuration`）

`press 110ms`（按压）· `switchToggle 260ms`（Tab 指示器内容）·
`focus 220ms`（输入框聚焦）· `ambient 7s`（底图光斑周期）。
Tab 卡片平移用 450ms + `Curves.easeOutBack`（液态回弹）。

## 6. 环境底图（`AmbientGlassBackground`）

- 八色光斑：薄荷(左上) / 冰蓝(右上) / 樱花粉(右中) / 薰衣草(左下) /
  暖杏(右下) / 柔黄(左中) / 湖青(下中) / 白高光(顶中)；
- 每枚光斑独立漂移（画 8 字）+ 独立频率呼吸（浓度 ±22%）；
- 纯 `dart:ui` 径向渐变绘制（无 Blur），双层 `RepaintBoundary` 隔离重绘；
- 设置页可关（`animate: false` 定格省电）。

## 7. 组件规范

| 组件 | 文件 | 关键约定 |
|---|---|---|
| `GlassCard` | `widgets/glass_card.dart` | 磨砂卡：`frost:false` 退化为染色玻璃（列表行必用）；`surfaceTint`+`tintStrength` 控染色；RimLight 描边左上 α0.72→右下 α0.06 |
| `SkeuoButton` | `widgets/skeuo_button.dart` | 按压四重反馈：渐变反向/高光翻转/阴影收缩/0.965 缩放；`glass:true` 为白玻璃次级款；**描边壳必须画在 ClipRRect 之外**（Border 在裁剪内会被裁半圈） |

## 8. 滚动物理（`ClampedBouncingScrollPhysics`）

通过 `GlassScrollBehavior` 挂在 `MaterialApp` 上全局生效：

- **拖动**：iOS 阻尼 + 软墙钳制 —— 前 64px 线性跟手，之后指数渐近
  至 76.8px（连续无跳变，永远有一丝弹性响应）；
- **惯性 fling**：速度按剩余距离解析预截（`distance ∝ v^1.42`），
  Android spline 到边**恰好停在边界**，不越界飞行；
- **越界松手**：弹簧收回边界，**初速置 0**（继承甩动速度会飞出）；
- 行为由 `test/design_system/physics_test.dart`（widget 级 3 条）+
  `physics_math_test.dart`（数学级 5 条）锁定。

## 9. 资产规范（麻将切图）

- 位置：`assets/tiles/`（+ `2.0x/`、`3.0x/` 变体，**替换图必须三档同步**，
  否则高密度屏仍加载旧图）；
- 规格：**透明底纯图案 PNG**，图片尺寸 = 图案尺寸（宽高比 0.13~1.03 各异，
  App 端 contain 统一视觉大小）；
- 牌面底色/圆角/阴影/边框全部由 `TileCard` 代码绘制，切图只负责图案；
- 命名：`tong_1..9` / `tiao_1..9` / `zhong` / `fa` / `bai`（见 `core/tile.dart`）。

## 10. 性能预算

- **同屏 BackdropFilter ≤ 4 个**：当前 = 牌池卡 + 手牌卡 + 底栏船体
  （+ 选中胶囊叠一层）。列表行/小 chip 一律 `frost: false`；
- 底图光斑是纯渐变绘制，无 Blur、无 ImageFiltered；
- `AnimatedContainer/AnimatedScale` 驱动的微动效不建 layer；
- debug 包掉帧属正常（shader JIT），性能判断以 release/profile 为准。
